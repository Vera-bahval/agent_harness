# harness

CP1-05: собственный агентный цикл, внутренний API запусков, отмена, бюджеты, JSONL и архивы. [Описание и ссылки на функции](../../docs/harness.md). Точка входа — [app.py](app.py).

`make test-harness` проверяет цикл на replay через настоящие сандбоксы. `make demo-agent` демонстрирует Б1.1. В CP1-06 добавлены постоянные сессии и публичный gateway: [описание](../../docs/client-gateway.md).
