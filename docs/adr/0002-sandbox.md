# ADR-0002: Docker-сандбокс и способ запуска

- Статус: proposed
- Дата: 2026-11-04

## Контекст

Нужна изоляция команд от управляющих сервисов, воспроизводимый Linux-запуск.

## Предложение

Для первого прототипа предложен отдельный контейнер на сессию, создаваемый manager через Docker API. Если используем host socket, он доступен только manager; daemon/socket нельзя монтировать в агентский сандбокс. Реальный способ подключения выбрать до реализации.

## Альтернативы

Rootless Docker: снижает привилегии daemon, нужно проверить лимиты и mounts. gVisor: дополнительная граница изоляции, сложнее настройка и совместимость. Host Docker socket: простой прототип, но компрометация manager даёт фактически root на хосте.

## Последствия и проверка

Это существенная граница доверия, а не полноценная защита хоста от взлома manager. Manager не принимает произвольные images/host paths/options от модели. Минимальные ограничения с первого контейнера; диск требует реальной квоты. Динамические контейнеры маркируются и очищаются отдельно от compose. Проверки: timeout, cancel дерева, cleanup, секрет-canary; полный hardening к ЧП2.
