# ADR-0003: HTTP-запросы и SSE-события клиента

- Статус: accepted
- Дата: 2026-11-04

## Контекст

Нужны подключение, команды, отображение выполнения и reconnect; сначала CLI, затем desktop.

## Решение

Команды через HTTP JSON, события через SSE с event_id. Токен в заголовке, версия в сообщениях. Cancel — отдельный запрос; reconnect — продолжение с известного event_id в пределах срока хранения.

## Альтернативы

WebSocket: двусторонний канал, сложнее собственные reconnect и корреляция. gRPC streaming: строгий контракт, дополнительные зависимости и ограничения клиентского стека.

## Последствия и проверка

Нужно определить буфер событий, окно восстановления и ответ на устаревший курсор. Локальный HTTP для разработки; для передачи токена между машинами нужен TLS или защищённый туннель. Проверки: неверный токен, отправка, поток, cancel, повторное подключение без повторного запуска.
