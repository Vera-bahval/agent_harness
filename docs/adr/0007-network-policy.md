# ADR-0007: Сеть разделена по роли сервиса

- Статус: accepted
- Дата: 2026-11-05

Сандбоксы запускаются с network=none. Управляющие сервисы общаются в internal backend; внешний доступ к провайдеру получает llm-proxy через отдельную egress-сеть. Публикуется только loopback-порт gateway. Альтернатива — общая сеть всех контейнеров — не даёт такого разделения доступа. Следствие: задача, которой нужен интернет, пока не поддерживается; расширение egress-политики требует отдельного решения. Проверки: test-sandbox и test-server, секреты/сеть/socket scope.
