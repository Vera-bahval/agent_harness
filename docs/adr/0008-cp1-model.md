# ADR-0008: Отдельная пара Sol low для ЧП1

- Статус: accepted
- Дата: 2026-11-05

## Решение

Для ЧП1 использовать cp1-sol-low: gpt-6.1-sol с reasoning low и Responses API. В одной текущей таблице AA индекс 35 против 33 у DeepSeek V4.1 Flash 1017 max. [Источники и дата](../model-selection.md).

## Альтернативы

Оставить mini none — доступна и проходит технические задачи, но допуск по индексу не подтверждён. Увеличить reasoning без проверки рейтинга — не доказывает соответствие порогу. Выбор low у Sol подтверждён отдельной строкой рейтинга и не требует максимального reasoning.

## Последствия

Добавлен адаптер Responses с stateless историей tool calls и encrypted reasoning, без хранения reasoning в трейсах. Предыдущие данные mini сохраняются отдельно. Пара не меняется внутри кампании, точный ответ model фиксируется. Итоговый выбор нескольких пар на данных A-11 остаётся открытым до ЧП3.
