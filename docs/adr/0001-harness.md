# ADR-0001: Свой харнес на Python

- Статус: proposed
- Дата: 2026-11-04

## Контекст

Нужен понятный агентный цикл и возможность сменить пару для БАФ.

## Предложение

Реализовать небольшой цикл с тремя инструментами, ограничением шагов/времени и заменяемым LLM-адаптером. Все действия с workdir идут через sandbox-manager.

## Альтернативы

Готовый open source харнес с закреплённой версией: больше функций, но больше кода для объяснения и интеграции. Агентный фреймворк: ускоряет оркестрацию, но скрывает часть механики.

## Последствия и проверка

Пишем обработку ошибок и контекста сами. Проверка: replay tool call → наблюдение → финал; неверные аргументы; таймаут; отсутствие локального исполнения. Не утверждаем, что свой харнес качественнее готового до сравнения на БАФ.
