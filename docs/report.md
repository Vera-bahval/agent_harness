## CP1-06: клиент и gateway

Проверено 2026-11-05: CLI подключается с токеном через публичный gateway, получает SSE и скачивает архив с проверкой SHA-256. Б1.1 на replay проходит курсовой чекер: [вывод CLI](../results/cp1-06/client.log), [результат чекера](../results/cp1-06/check.json).

Прошли 8 HTTP/SSE-тестов клиента с mock-харнесом, 3 сквозных теста Compose (включая два сообщения с сохранением файлов и истории), регрессия 8 тестов харнеса, 13 unit и 12 contract, smoke четырёх сервисов. Отдельно прошёл SIGKILL/restart gateway при активной команде: новый epoch отклонил старый запрос, сандбокс освобождён до готовности нового gateway. API OpenAI в этом этапе не вызывался.

Приняты ADR-0003 и ADR-0006. Границы: один gateway, состояние в памяти, локальный HTTP на loopback; desktop и mount остаются на ЧП2. Следующий этап — CP1-07, раннер БАФ через этот API.
