# Клиент

В CP1-06 реализуем CLI: URL/токен, сессия, сообщение, события, cancel/reconnect. В ЧП2 добавим desktop-оболочку, выбор локальной папки и настоящий mount. CLI остаётся для автотестов.

Исходников и действующих команд пока нет. [План](../docs/checkpoint-1.md), [транспорт](../docs/adr/0003-client-transport.md).
