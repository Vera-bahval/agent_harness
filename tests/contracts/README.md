# Контрактные тесты

Запуск из корня: `make test-contracts`, после установки `requirements-dev.txt` в `.venv`.

12 тестов проверяют схемы JSON Schema 2020-12 и примеры всех типов сообщений, обязательные поля, неизвестные версии/поля, границы таймаутов, состояние/результат, ошибки, пути, бинарное содержимое и отсутствие произвольных env/host paths в командах. В тесте примеров запрещены сетевые соединения.

Это проверки формы сообщений. Авторизация, часы/сроки, порядок событий, соответствие operation_id, идемпотентность, cancel, cleanup, symlink traversal и секреты проверяются интеграционно в tests/infra после реализации сервисов.
