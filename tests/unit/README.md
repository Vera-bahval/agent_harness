# Тесты компонентов

`make test-unit` запускает 5 проверок HTTP-bootstrap: здоровая зависимость, каскад отказа при работающем /live, ошибки/таймауты зависимости, 501 для нереализованных операций, отсутствие отражения входных данных в ошибке. Используются временные локальные HTTP-порты; внешняя сеть не нужна.

Ещё 8 тестов проверяют инструменты, нормализацию ответа/usage, историю tool results, параметры провайдера, безопасные ошибки и replay-наблюдения. Итого 13. Добавлена проверка credit_balance_exhausted / insufficient_quota. Агентный цикл с Docker проверяется через `make test-harness`.

CP1-07 добавляет 9 тестов раннера БАФ (task.yaml, архив, чекер, исходы и cleanup). Всего 22 unit-теста.

CP1-08: ещё 5 тестов регистрации и чекеров простых Б2–Б5 с положительными и отрицательными подслучаями. Всего 27 unit-тестов.

Подготовка ЧП1: 3 теста полного набора/чекеров и 2 теста Responses API. Всего 32 unit-теста. Общая команда — make test-ci.
