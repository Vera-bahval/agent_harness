# Раннер БАФ

Реализация — CP1-07. Один запуск: task.yaml → чистая fixture → штатный клиентский API → collect → доверенный check.py вне сандбокса → JSONL → release в finally.

Должен поддерживать выбор пары, задач, числа повторов и режимов smoke/quality. Для ЧП1: сначала 5 простых, затем 15 задач Б1–Б5 по одному повтору. Результаты replay не считаются измерением качества реальной модели.
