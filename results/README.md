# Сырые результаты

- baf/: JSONL по паре и запуску, рядом конфигурация и summary.
- traces/: события с идентификаторами для разбора запусков.
- bench/: данные будущих замеров ФС и sandbox.

Сохранены демонстрации CP1-05/06 и прогоны раннера CP1-07 в baf/. Контрольные обезличенные прогоны коммитить вместе с отчётом; результаты не игнорируются целиком. Перед публикацией проверить отсутствие ключей, токенов и приватных данных; local/ игнорируется.
